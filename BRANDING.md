# GoreeCloud Profile Branding

Branding authority: `GoreeCloud/goreecloud-branding-assets`.

The canonical GoreeCloud platform mark is `official/goreecloud-logo.svg`. This public profile repository may vendor a synchronized copy for rendering because the canonical branding repository is private, but the vendored copy must not become an independent authority.

All future profile logos, social artwork, banners, identity graphics, and related GoreeCloud branding must originate in the unified branding repository first. Branding does not establish project maturity, release, security, privacy, continuity, or production-readiness claims.
