## Continuing application direction

All current and future GoreeCloud application roadmap work must target original GoreeCloud-owned native implementations built for their GoreeCloud role. Complete upstream applications or forks may be used only as bounded migration, compatibility, testing, continuity, historical, or engineering-reference inputs. Narrow mature technical foundations may remain when replacing them would materially increase security, cryptographic, protocol, standards, codec, rendering, operating-system, runtime, or interoperability risk.

## Integral Platform Systems

Current platform-wide conformance work is governed by Platform Contract 2.0 and the authoritative Drive governance. In-scope components must be evaluated explicitly against all nine Integral Platform Systems:

1. GoreeCloud Manager
2. Privacy Shield
3. Wardveil Security
4. Everkeep
5. Glaze
6. GoreeCloud Mesh
7. GoreeCloud Identity
8. GoreeCloud Policy
9. GoreeCloud Observability

A roadmap reference to an Integral Platform System does not establish implementation, conformance, deployment, qualification, or production acceptance. Those claims require the evidence defined by the current governing contracts and repository-local acceptance records.

## Migration note

The former Drive roadmap named only Glaze UI, Wardveil Security, Privacy Shield, and Everkeep because it predated the current nine-system model. That wording is preserved as migration history in the Drive sources and repository history but is not current platform authority.
