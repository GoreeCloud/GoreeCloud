## Maintenance

When repositories are created, transferred, archived, made public, made private, or renamed:

1. Re-verify the owned repository set from GitHub.
2. Update the counts in this document.
3. Update the public repository list when public membership changes.
4. Update `repositories.public.json` for machine-readable public inventory changes.
5. Preserve the private-repository privacy boundary unless GoreeCloud policy explicitly changes it.
6. Do not infer lifecycle or production state from repository presence alone.
