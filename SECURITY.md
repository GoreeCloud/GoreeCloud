# Security reporting

GoreeCloud prioritizes privacy, safety, and responsible maintenance, but this documentation repository does not represent a production security product or a guaranteed support service.

Please **do not publish** vulnerability details, exploit instructions, credentials, personal data, or private network information in a public GitHub issue or pull request.

Use GitHub's **private vulnerability reporting** for this repository: open the [Security tab](https://github.com/GoreeCloud/GoreeCloud/security), choose **Report a vulnerability**, and describe the issue privately. This reporting channel was verified enabled on November 11, 2026. If GitHub's private reporting flow is temporarily unavailable, contact the maintainer through an existing trusted private channel instead; do not put exploit details in public issues. No dedicated security inbox or response-time guarantee is asserted here.

For vulnerabilities in a specific GoreeCloud application or service, use that repository's applicable private reporting instructions. GoreeShield governs privacy; Wardveil governs cybersecurity; GoreeCloud Mesh coordinates integrations subject to both.
